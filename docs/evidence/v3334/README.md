# v3.334 西藏 A/B 类别与无公开位次边界证据

## 结论

- 西藏普通类控制线必须按 A 类、B 类分别判断，不能只凭分数跨类别套线。
- A 类考生为区内世居两代（含两代）以上少数民族考生。
- B 类考生为汉族及区外少数民族考生。
- 2025 年 22 条官方控制线已统一写入考生类别，其中普通类 12 条、艺体类 8 条、部队生源 2 条。
- 已核验的官方公开渠道未提供可计算一分一段，西藏位次换算保持 0。

## 安全边界

网站只在省份为西藏时显示 A/B 类别选择。未选择类别时，推荐可信度强制为 C，并提示不得跨类别混用；泛称“少数民族考生”不会自动判为 A 类。没有考生本人从官方渠道取得的正式位次时，系统不按分数推算位次，不生成位次安全边界或录取概率。
