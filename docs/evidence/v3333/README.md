# v3.333 北京 2025 本科投档分位次对齐证据

## 结论

- 北京考试院 2025 年一分一段表共 347 条，统计分数明确包含全国性照顾加分。
- 北京本科普通批投档表共 1397 条院校专业组最低总分，使用六科 750 分本科录取总成绩。
- 1271 条非北京市属高校记录与一分一段口径兼容，补充最低分换算位次。
- 126 条北京市属高校记录可能使用仅限市属高校的地方 5 分，保持无位次。
- 580 条专科运行记录只使用语文、数学、外语三科总分，保持无位次。

## 安全边界

换算位次来自同年省级分数段，不是投档表直接公布的原生位次，不等同于组内具体专业录取最低位次，也不构成录取概率。地方加分口径和专科三科总分均未强行套表。
